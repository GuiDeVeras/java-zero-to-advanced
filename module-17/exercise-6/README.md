Exercise 6
	In the vote count of an election, several voting records are generated containing the candidate's name and the number of votes (in .csv format) they obtained in a ballot box. You must write a program to read the voting records from a file, and then generate a consolidated report with the totals for each candidate.

Input file example:
	Alex Blue, 15
	Maria Green, 22
	Bob Brown, 21
	Alex Blue, 30
	Bob Brown, 15
	Maria Green, 27
	Maria Green, 22
	Bob Brown, 25
	Alex Blue, 31

Execution:
	Enter file full path: c:\temp\in.txt
	Alex Blue: 76
	Maria Green: 71
	Bob Brown: 61
